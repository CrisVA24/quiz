# Quiz JavaScript

Aplicación web de trivia desarrollada principalmente con JavaScript.

La aplicación permite responder preguntas de selección única, recibir retroalimentación sobre cada respuesta, consultar la puntuación final y volver a intentar la trivia.

También incluye un editor que permite modificar las preguntas existentes, editar sus opciones y respuesta correcta, y agregar nuevas preguntas.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Cinco preguntas precargadas.
- Cuatro opciones por pregunta.
- Una única respuesta correcta por pregunta.
- Renderizado dinámico mediante manipulación del DOM.
- Feedback de respuesta correcta o incorrecta.
- Seguimiento del progreso.
- Cálculo de puntuación.
- Pantalla de resultados.
- Reinicio de la trivia.
- Edición de preguntas existentes.
- Edición de opciones.
- Cambio de respuesta correcta.
- Creación de nuevas preguntas.
- Navegación entre las pantallas sin recargar la página.
- Almacenamiento de los cambios en memoria durante la sesión.

## Cómo ejecutar el proyecto
1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir index.html en un navegador web.

No se requieren dependencias adicionales.

## Almacenamiento

Las preguntas y modificaciones se mantienen únicamente en memoria mientras la aplicación está abierta.

Al recargar la página, la aplicación vuelve a las cinco preguntas originales.
